# REST API HTTP Method 예시

## GET
데이터를 조회(Read)할 때 사용하는 메서드.

### 전체 Task 조회
```http
GET /tasks
```

### ID가 1인 Task 조회
```http
GET /tasks/1
```

### 완료된 Task만 조회 (Query Parameter 사용)
```http
GET /tasks?completed=true
```

- `completed=true`는 Query Parameter.
- 완료된(Task가 완료 상태인) 데이터만 조회 가능.

---

## POST
새로운 데이터를 생성(Create)할 때 사용하는 메서드.

### 새로운 Task 생성
```http
POST /tasks
```

예시 요청 데이터
```json
{
  "title": "밥먹기",
  "completed": false
}
```

---

## PATCH
기존 데이터의 일부를 수정(Update)할 때 사용하는 메서드.

### ID가 1인 Task 수정
```http
PATCH /tasks/1
```

예시 요청 데이터
```json
{
  "completed": true
}
```

→ Task의 `completed` 값만 수정 가능.

---

## DELETE
기존 데이터를 삭제(Delete)할 때 사용하는 메서드.

### ID가 1인 Task 삭제
```http
DELETE /tasks/1
```

→ ID가 1인 Task를 삭제 가능.

---

## 정리

| Method | URL | 설명 |
|--------|-----|------|
| GET | `/tasks` | 전체 Task 조회 |
| GET | `/tasks/1` | ID가 1인 Task 조회 |
| GET | `/tasks?completed=true` | 완료된 Task 조회 (Query Parameter) |
| POST | `/tasks` | 새로운 Task 생성 |
| PATCH | `/tasks/1` | ID가 1인 Task 일부 수정 |
| DELETE | `/tasks/1` | ID가 1인 Task 삭제 |
